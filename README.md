# Accenture Financial Performance Dashboard (FY2025)
## 📊 Project Overview
This project focuses on analyzing the financial and strategic performance of Accenture plc for FY2025 using Microsoft Excel.
The objective is to transform financial data from Accenture's Annual Report 2025 into meaningful business insights through an interactive Excel dashboard.
The dashboard provides an executive-level overview of financial performance, revenue growth, profitability, industry-wise revenue distribution, geographical revenue contribution, and key business performance indicators.
## 🎯 Project Objectives
- Analyze Accenture's financial performance for FY2025.
- Track revenue and profitability trends.
- Compare operating income and net income across financial years.
- Evaluate operating and net profit margins.
- Analyze revenue by industry and geographical region.
- Develop an executive financial dashboard using Microsoft Excel.
- Generate meaningful business insights to support decision-making.

## 💡 Key Business Insights
1. **Revenue Growth:** Accenture generated $69.7 billion in FY2025 revenue, representing 7.4% growth compared with FY2024.
2. **Operating Income:** Operating income increased by 6.6% to $10.2 billion.
3. **Net Income:** Net income increased by 5.6% to $7.8 billion.
4. **Free Cash Flow:** Free cash flow increased by 26.2% to $10.9 billion.
5. **Operating Margin:** Operating margin was 14.7%, declining by 11 basis points compared with FY2024.
6. **Geographical Performance:** The Americas represented the largest geographical revenue contribution.
